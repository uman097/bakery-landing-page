# Sweet Crumb Bakery - Landing Page

Task 1: Responsive landing page for a bakery (Ezitech Internship).

## What Was Built
- **Header:** Bakery logo and navigation links (Home, About, Contact).
- **Hero Section:** Main heading (h1), intro text, "Book a Tasting" button, and cake image.
- **Three Features:** Highlighted cards for Fresh Daily, Custom Designs, and Private Tasting.
- **Footer:** Visiting hours, contact information, and copyright.

## Requirements Followed
- Built with **pure HTML & CSS only** (No Bootstrap, no frameworks).
- Responsive at **375px** (Mobile) and **1440px** (Desktop).
- No horizontal scrolling at any screen width.
- Heading hierarchy maintained: `h1` ➔ `h2` ➔ `h3`.
- Meaningful `alt` text on images for accessibility.
